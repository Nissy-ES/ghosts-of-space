# Ghosts of Space
### NASA Space Apps Challenge 2026 — Abandoned but not Forgotten

**Tagline:** Their missions ended. Their stories didn't.

## What this prototype is
An interactive educational storytelling website about NASA hardware left on the Moon, Mars and elsewhere. Instead of presenting a catalogue of spacecraft, it guides school-age and casual audiences through short mission narratives: why the hardware existed, what happened during the mission, what scientists learned, and what legacy remained.

## Run locally
Open `index.html` in a browser. No build step or server is required.

## Included
- Responsive single-page website
- Interactive artifact archive
- Five story experiences
- Chapter-by-chapter storytelling
- Mission timeline
- Accessibility-minded typography and keyboard activation
- NASA resource links
- No external API dependency for the core demo

## Featured artifacts
- Sojourner — Mars Pathfinder
- Spirit — Mars Exploration Rover
- Ingenuity — Mars 2020
- Apollo Lunar Roving Vehicle
- NEAR Shoemaker — 433 Eros

## Suggested demo flow
1. Open the landing page.
2. Click "Begin the journey".
3. Choose Ingenuity to demonstrate the strongest visual/engineering story.
4. Walk through the five chapters.
5. Return to the archive and show the timeline.
6. End with the line: "The missions ended. The legacy continues."

## Tech
HTML, CSS, JavaScript. No database required for the MVP.
