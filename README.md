# Ghosts of Space

### NASA Space Apps Challenge 2026 : Abandoned but not Forgotten Storytelling about NASA's Discarded Equipment on the Moon and Mars

**Tagline:** Their missions ended. Their stories didn't.

## What this project is

Ghosts of Space is an interactive educational storytelling website about NASA hardware left on the Moon, Mars and elsewhere.

Instead of presenting a simple catalogue of spacecraft, it guides school-age and casual audiences through short mission narratives: why the hardware existed, what happened during its mission, what scientists learned, and what legacy remained.

## Run locally

Download or clone this repository and open `index.html` in a web browser. No build step or server is required.

## Features

- Responsive single-page website
- Interactive artifact archive
- Five artifact story experiences
- Chapter-by-chapter storytelling
- Text-to-speech narration for story chapters
- Mission timeline
- Keyboard-accessible artifact selection
- NASA resource links
- No external API dependency for the core demo

## Featured artifacts

- Sojourner - Mars Pathfinder
- Spirit - Mars Exploration Rover
- Ingenuity - Mars 2020
- Apollo Lunar Roving Vehicle
- NEAR Shoemaker - 433 Eros

## Demo flow

1. Open the landing page.
2. Click "Begin the journey".
3. Select Ingenuity to explore its mission.
4. Navigate through the five story chapters.
5. Demonstrate the text-to-speech narration.
6. Return to the archive and explore the timeline.
7. End with: "The missions ended. The legacy continues."

## Technology

HTML, CSS and JavaScript. No database or external API is required for the core prototype.

## Sources and verification

NASA and NSSDCA resources are used as references for the mission stories. Individual artifact facts and source links should be verified against primary NASA sources before final publication.
